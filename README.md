# practice X 엔진 (SANDBOX)

가상 브랜드 practice X의 가상 세계 엔진입니다. 모든 출력은 시뮬레이션(SIM) 데이터이며 실제 판매·결제·발송은 없습니다.

## 구성
- 가상 시계: 24시간 연속. 실제 24시간 = 가상 210일(30배, 2026-10-31 18:20 KST 이후), 가상 2026-11-01 ~ 2028-01-15(440일)
- 공급(납기·불량·가격 인상), 수요(자연·광고·외부몰), 가상 장부(현금·후불·재고·반품), 월간 보고, 광고 비용 대비 전환 효율 마감 보고
- 상태·기록은 Notion 표에 쓰고, 계획값은 `plan/`에 둡니다.

## 실행
- 자동: Actions의 `engine-loop`가 2분마다 시계를 전진시키고 약 5시간 30분마다 스스로 다시 실행됩니다. 필요한 비밀값은 `NOTION_TOKEN` 하나입니다(저장소 Secrets).
- 수동: `engine-tick`(한 번 전진), `engine-run`(status / init / step)
- 로컬 시험: `python3 -m unittest discover -s tests -t .`

공개 저장소이므로 비밀값을 코드나 기록에 넣지 마세요.
